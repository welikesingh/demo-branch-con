git remote add origin https://github.com/welikesingh/git-stash-test.git

     git remote add origin <github-repository-url> 
		connects your local Git repository to a remote repository on GitHub
		origin → the name/alias you give to the remote repository. origin is the conventional name.
		Local Repository
			   |
			   | origin
			   ↓
		GitHub Repository


git push -u origin main

		Here: 
		origin → GitHub repository
		main   → branch you want to push

        The -u establishes an upstream/tracking relationship, so later you can usually just use: git push
